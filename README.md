## 📚 这是什么？

最近在准备 **xkl / hw 材料、结构、电子材料相关岗位**，整理资料时发现题目分散在 PDF、Word、截图、网页和聊天记录里，复习效率很低，于是把题库做成了一个可以直接刷的离线 HTML 工具。

当前版本主要覆盖 **高分子 / 材料研发 / 结构与材料工程** 等方向，尽量把「找题 → 刷题 → 看解析 → 复盘 → 模拟 → 面试准备」放在一个页面里完成。

> 打开一个 HTML，就能开始刷题。无需安装，Windows / macOS / Android / iOS 均可使用现代浏览器打开。

## ✨ 功能一览

- **专项刷题**：玻璃、陶瓷、金属、焊接、高分子五大专项，可按专题、题型、来源筛选。
- **真题与回忆题**：保留真实来源记录，来源答案与科学审定答案分层展示；缺失信息不强行补造。
- **45题实战**：20 单选 + 15 多选 + 10 判断，60 分钟模拟笔试节奏。
- **错题复盘**：自动记录错题、错误次数和掌握状态，支持顺序 / 随机二刷。
- **技术面试**：材料与结构岗位常见技术面试题集中复习。
- **AI 助教**：支持 AI 结构化解读、自由追问、选中文字问 AI、AI 随机出题与个人 AI 题库。
- **学习笔记**：随手记录知识点、易错点、面试表达，可与当前题目关联。
- **公式显示**：内置公式渲染，支持常见 LaTeX 行内公式和独立公式。
- **离线学习数据**：作答、错题、实战、笔记等保存在本机，可导入 / 导出学习记录。
- **手机 / 电脑适配**：响应式布局、深色模式、沉浸刷题。

## 🚀 使用方法

1. 打开右侧 **Releases**，或点击上方 **「下载最新版 HTML」**。
2. 下载 `xkl-hw-gaofenzi-...html`。
3. 直接用 Chrome / Edge / Safari 等现代浏览器打开。
4. 手机端可以把 HTML 发到微信 / 文件管理器中，再选择浏览器打开。
5. 如需使用 AI 功能，在页面右上角 **AI设置** 中填写自己的 DeepSeek API Key。

> API Key 只用于你自己的浏览器向模型接口发起请求。建议仅在个人可信设备上使用，并自行保管 Key。

## 🧠 题库处理原则

这个项目不是简单把资料复制进网页。真题数据尽量遵循以下原则：

- **来源事实保留**：原题、原答案、原始文本 / 图片等来源信息尽量保留。
- **科学审定独立**：科学答案不会因为资料给了某个字母就直接照抄。
- **不强行制造答案**：题目缺条件、选项损坏或科学上没有唯一答案时，暂停自动判分。
- **重复来源不合并投票**：同一道题在不同套卷出现时保留 occurrence，不用“多数答案”代替科学判断。
- **解析强调理解**：尽量说明核心原理、选项判断、易错点、适用边界和工程联系。

## 🤖 AI 功能说明

完整版 HTML 支持 DeepSeek API。AI 相关功能包括：

- 单题 **AI结构化解读**；
- 全局 **AI助教** 多轮对话；
- 选中文字后快速 **问AI**；
- AI 随机出题并保存到个人 AI 题库；
- 结合题目继续追问、解释术语、补充例子；
- LaTeX / 数学公式规范渲染。

AI 输出仅作为学习辅助，重要知识点仍建议结合教材、标准和可靠资料核验。
